## The line

> I'm allergic to my desk — every time I sit at it, I break out in meetings.

One line, 74 characters. The field is drowning in backs that file complaints, cats that hide keys, smart locks that only recognise the cat, parrots that call the boss, and toddlers with permanent markers — this one turns the allergy itself into the joke: the allergic reaction to the desk is breaking out in meetings, the one symptom no office worker wants.

## How it runs

`main.py` (Python 3, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` — UTF-8, no trailing newline — and leaves the file readable by every user (0644, folders 0755).

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
